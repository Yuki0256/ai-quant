# 📊 Task 1 — AI 量化交易作业

> **任务标记**: `task1` · 目录: `ai-quant/`

数据获取、指标计算与报告生成。

## 项目结构

```
ai-quant/
├── fetch_data.py          # Tushare 数据获取
├── generate_report.py     # 报告生成脚本
├── index.html             # 报告展示页面
├── data/                  # 数据文件
├── reports/               # 生成报告输出
└── 量化交易作业报告.pdf   # 最终报告
```

## 功能

- 通过 Tushare Pro API 获取股票数据
- 自动化生成量化交易分析报告
- 支持 HTML 与 PDF 格式输出
